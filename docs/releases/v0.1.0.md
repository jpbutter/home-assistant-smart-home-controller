# v0.1.0 — Initial developer preview

The first public developer preview establishes a small, testable boundary around
the Home Assistant REST API.

## Highlights

- Async health, entity-state, entity-list, and service requests.
- Typed validation of Home Assistant state payloads.
- Pure threshold rules that return explainable action proposals.
- Read-only CLI commands for API checks and entity inspection.
- Actionable validation for missing Home Assistant settings.
- Tests that run without a Home Assistant instance.
- Python 3.11–3.14 CI, strict type checking, linting, and package validation.

## Intended audience

Developers exploring external Home Assistant orchestration who want to keep
decision logic separate from network side effects.

## Limitations

There is no scheduler, WebSocket subscription, YAML loader, persistent state,
automatic retry policy, or production executor. The public API may change before
v1.0. This software is not a safety controller.

## Installation

Install from the tagged source:

```bash
python -m pip install "git+https://github.com/jpbutter/home-assistant-smart-home-controller.git@v0.1.0"
```
