# Support

Use a GitHub issue when you can provide a reproducible bug report or a scoped
feature proposal. Search existing issues before opening a new one.

This project does not provide support for general Home Assistant installation,
networking, device pairing, or vendor integrations. Those questions belong in
the official Home Assistant documentation and community channels.

Security issues must follow [SECURITY.md](SECURITY.md), not the public issue
tracker. Never post tokens or real household telemetry.
