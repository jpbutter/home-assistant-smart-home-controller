# Changelog

## [0.1.0] - 2026-09-13

### Added

- Async client for state reads and service calls
- Typed entity-state parsing
- Pure threshold-rule evaluation
- Minimal state CLI
- Synthetic YAML examples
- Tests, CI and security notes

### Known limitations

There are no WebSocket subscriptions, durable schedules, retries or production secret-store integrations yet.
